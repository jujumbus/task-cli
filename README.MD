# Task CLI — Task Tracker на Go

Консольное приложение для управления задачами, написанное на языке Go.

Проект позволяет создавать задачи, изменять их описание, удалять, отслеживать статус выполнения и просматривать задачи по категориям.

Данные сохраняются локально в файле `tasks.json`.

## Возможности

- Создание задач с уникальным ID.
- Просмотр всех задач.
- Фильтрация задач по статусам.
- Изменение описания задачи.
- Удаление задачи по ID.
- Изменение статуса задачи.
- Автоматическое сохранение даты создания и обновления.
- Сохранение и загрузка задач в формате JSON.
- Обработка неверных команд и аргументов.
- Справка по доступным командам.

## Технологии

- **Go** — основной язык программирования.
- **JSON** — формат хранения задач.
- **Стандартная библиотека Go** — работа с файлами, временем, аргументами командной строки и обработкой ошибок.

Сторонние библиотеки не используются.

## Запуск

Для запуска необходимо установить Go.

Откройте терминал в папке проекта и выполните:

```powershell
go run . help
```

Команда выведет список доступных действий.

## Доступные команды

| Команда | Описание |
|---|---|
| `add <описание>` | Создать новую задачу |
| `list` | Показать все задачи |
| `list done` | Показать выполненные задачи |
| `list progress` | Показать задачи в процессе |
| `list todo` | Показать задачи, к которым ещё не приступили |
| `update <ID> <описание>` | Изменить описание задачи |
| `delete <ID>` | Удалить задачу |
| `done <ID>` | Отметить задачу как выполненную |
| `progress <ID>` | Отметить задачу как находящуюся в процессе |
| `help` | Показать справку |

## Примеры использования

Создание задачи:

```powershell
go run . add Изучить Go
```

Просмотр всех задач:

```powershell
go run . list
```

Изменение описания:

```powershell
go run . update 1 Изучить функции в Go
```

Перевод задачи в статус «В процессе»:

```powershell
go run . progress 1
```

Отметка задачи как выполненной:

```powershell
go run . done 1
```

Просмотр выполненных задач:

```powershell
go run . list done
```

Удаление задачи:

```powershell
go run . delete 1
```

## Структура задачи

Каждая задача содержит следующие поля:

- `ID` — уникальный идентификатор задачи.
- `Description` — описание задачи.
- `Status` — текущий статус.
- `CreatedAt` — дата и время создания.
- `UpdatedAt` — дата и время последнего изменения.

В приложении используются три статуса: `Выполнить`, `В процессе` и `Выполнено`.

## Хранение данных

Задачи автоматически сохраняются в файл `tasks.json` в текущей рабочей папке.

Если файл отсутствует, приложение начинает работу с пустым списком задач. При сохранении первой задачи файл создаётся автоматически.

Файл `tasks.json` добавлен в `.gitignore`, поэтому локальные задачи не загружаются в GitHub.
